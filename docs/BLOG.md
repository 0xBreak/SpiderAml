# Как добавить пост в блог

Посты — файлы `.mdx` в `web/src/content/blog/`. Имя файла = адрес страницы: `kak-raspoznat-piramidu.mdx` →
`https://spideraml.com/blog/kak-raspoznat-piramidu`. Только латиница, цифры и дефисы.

## Шаблон

```mdx
export const meta = {
  title: "Как распознать пирамиду за 5 минут",          // заголовок (и в поиске Google)
  description: "Пять признаков, которые видно до вложения денег.",  // 1–2 предложения для списка и превью ссылки
  date: "2026-11-02",                                   // ГГГГ-ММ-ДД, по ней сортировка (новые сверху)
  draft: true,                                          // true — виден только при разработке; убрать, чтобы опубликовать
};

Вступление обычным текстом.

## Подзаголовок

- пункт списка
- **жирный**, *курсив*, [ссылка](https://example.com), [ссылка на наш раздел](/check)

> Цитата или важное предупреждение.

![Подпись к картинке](/blog/kak-raspoznat-piramidu-1.png)
```

## Что нужно для поста

| Что | Обязательно | Где |
|---|---|---|
| Заголовок, описание, дата | да | `meta` в начале файла |
| Текст | да | ниже `meta`, Markdown |
| Картинки | нет | `web/public/blog/`, в тексте `/blog/имя.png`. PNG/JPG до ~500 КБ, ширина 1200–1600 px |
| Ссылки на свои разделы | нет | `/check`, `/token`, `/whales`, `/sanctions` |

Правило текста: про конкретные адреса и проекты — «высокий риск» и причина, без слов «мошенник» и обвинений.

## Публикация

1. Положите файл (и картинки), проверьте локально: `cd web && npm run dev` → http://localhost:3000/blog
2. Уберите `draft: true`.
3. `git add web/src/content/blog web/public/blog && git commit -m "Блог: …" && git push`
4. На сервере: `/srv/spideraml/data/deploy/update.sh` — сайт пересоберётся (~2 минуты).
