Состояние на 2026-11-04: сайт работает на spideraml.com (Hetzner, Cloudflare Tunnel), деплой через GitHub Actions;
слой данных приватный и выкладывается отдельно. Часть ниже сделана локально и ждёт выкладки.

## Метрики, на которые смотреть
- Посетители и откуда пришли (`bun run stats`, админка): какие каналы работают; боты считаются отдельно.
- Проверки по результату: насколько часто люди проверяют действительно опасные адреса (примеры из подсказок считаются отдельно).
- Клики «Отправить с проверкой», заявки: вовлечённость.
- Ошибки (`check error:…`): что ломается у пользователей; введённый вместо адреса текст не хранится.
